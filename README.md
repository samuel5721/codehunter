# 색깔 사냥

화면에 뜬 색과 닮은 물건을 제한 시간 안에 찾아 휴대폰으로 찍는 실시간 파티 게임입니다.
시간이 끝나면 사진마다 목표색과 얼마나 비슷한지 100점 만점으로 채점해, 찍은 사진과 함께 순위를 보여 줍니다.
개인전과 팀전을 지원합니다.

서버가 필요 없습니다. GitHub Pages에 올리기만 하면 됩니다.

## 진행 방법

1. **진행자**: 노트북·TV처럼 다 같이 보는 큰 화면에서 사이트를 열고 **진행자 화면 열기**를 누릅니다.
2. **참가자**: 휴대폰 카메라로 화면의 QR을 찍어 들어오거나, 사이트 첫 화면에 방 코드(영문 4글자)를 입력합니다.
3. 진행자가 설정을 고르고 **1라운드 시작**을 누릅니다.
   - 방식: 개인전 / 팀전(2~4팀, 참가자가 팀을 고르거나 진행자가 자동 배정)
   - 제한 시간: 30초 / 1분 / 1분 30초 / 2분
   - 라운드: 1 / 3 / 5 / 7
   - 채점: 후하게 / 보통 / 깐깐하게
   - 색 정하기: 라운드마다 랜덤 / 직접 고르기
4. 3초 카운트다운 후 큰 화면 전체가 목표색으로 바뀌고 타이머가 돕니다.
   참가자 휴대폰에는 카메라와 목표색이 함께 떠요. 시간 안에 몇 번이든 다시 찍을 수 있고, 마지막 사진이 점수에 들어갑니다.
5. 시간이 끝나면 큰 화면에서 **순위 발표 쇼**가 시작됩니다 (아래 참고). 끝나면 사진과 순위, 누적 순위가 정리돼 나와요.
6. 마지막 라운드가 끝나면 **최종 결과 발표**로 시상식을 하고 전체 순위를 보여 줍니다.

## 순위 발표 연출 (`js/reveal.js`)

라운드 결과 (큰 화면, 개인전 약 17초 / 팀전 약 21초)
1. **스캔**: 사진들이 흩어져 등장하고, 조준 네모가 사진을 훑다가 목표색과 가장 비슷한 곳에 '찰칵' 고정돼요. 찾은 색이 동그라미로 튀어나옵니다.
2. **색 경주**: 각자 찾은 색 동그라미가 목표색 결승선을 향해 달려요. 점수만큼 멀리 가고 점수가 함께 올라갑니다. 다 도착하면 순위대로 줄이 바뀌어요.
3. **팀 대결** (팀전만): 팀 막대가 솟아오르고 1등 팀에 표시가 붙어요.
4. **TOP 3**: 3등 카드, 2등 카드가 떨어지고 → 드럼롤과 함께 "1등은…" → 섬광, 빛줄기와 함께 1등 사진이 크게 등장, 꽃가루.
5. 결과 화면 오른쪽 **누적 순위**가 지난 순서에서 새 순서로 자리를 바꾸고 ▲▼ 변동이 표시돼요.

최종 시상식: 그동안의 목표색과 라운드 1등을 돌아보고 → 3등, 2등 단상이 솟아오르고 → 불이 꺼진 무대를 스포트라이트가 훑다가 → 1등 단상과 함께 우승자 발표.

휴대폰: 큰 화면에서 발표하는 동안은 "순위 발표 중!"만 보여 스포일러가 없고, 발표가 끝나는 순간 슬롯머신처럼 내 순위가 돌다가 멈춥니다 (진동, 점수 카운트업, 1등이면 꽃가루).

- 어느 장면이든 **건너뛰기** 버튼이나 Esc·Space·Enter로 바로 결과로 넘어가요.
- 결과 화면의 **발표 다시 보기**, 최종 화면의 **시상식 다시 보기**로 다시 틀 수 있어요.
- 기기에서 '동작 줄이기'를 켜 두면 연출 없이 바로 결과를 보여 줍니다.

점수 계산:
- 개인 점수 = 라운드 점수의 합
- 팀 점수 = 라운드마다 팀원 점수 평균(사진을 못 낸 사람은 0점)의 합. 인원이 달라도 공평해요.

## GitHub Pages에 올리기

1. GitHub에서 새 저장소를 만듭니다 (예: `color-hunt`, Public).
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 내용(`index.html`, `css`, `js`, `lib` 폴더 전부)을 끌어다 놓은 뒤 **Commit changes**.
   - 폴더째 끌어 놓으면 폴더 구조가 그대로 올라갑니다.
3. 저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 고르고 **Save**.
4. 1~2분 뒤 `https://내아이디.github.io/color-hunt/` 주소로 접속하면 됩니다.

git으로 올릴 때:

```bash
cd colorhunt
git init && git add . && git commit -m "색깔 사냥"
git branch -M main
git remote add origin https://github.com/내아이디/color-hunt.git
git push -u origin main
```

카메라는 `https://`에서만 켜지는데, GitHub Pages는 자동으로 https라서 따로 할 일이 없습니다.
내 컴퓨터에서 먼저 해 보려면 `python3 -m http.server 8000` 후 http://localhost:8000 (휴대폰 카메라는 https가 필요해서, 휴대폰 테스트는 Pages에 올린 뒤에 하세요).

## 실시간 연결 방식과 주의할 점

- 휴대폰과 진행자 화면이 **WebRTC로 직접 연결**됩니다 (라이브러리: PeerJS). 처음 서로를 찾을 때만 PeerJS의 무료 공개 중계 서버를 거쳐요.
- **진행자 화면이 곧 방**입니다. 게임 중에는 진행자 탭을 닫지 마세요.
  - 실수로 새로고침해도 같은 방 코드로 다시 열리고, 참가자들은 자동으로 다시 연결됩니다 (진행 중이던 라운드는 취소, 점수는 유지).
- 참가자가 새로고침하거나 잠깐 끊겨도 자동으로 다시 들어오고 점수는 그대로입니다.
- **모두 같은 Wi-Fi**에 있으면 가장 안정적입니다. 일부 회사·학교 네트워크나 모바일 데이터에서는 직접 연결이 막힐 수 있는데, 이때는 PeerJS의 공개 릴레이(TURN) 서버를 거쳐 연결을 시도합니다.
- 공개 중계 서버가 불안정할 때는 직접 띄운 PeerJS 서버를 쓸 수 있어요. 진행자 화면 주소 뒤에 붙이면 참가 QR에도 자동으로 따라갑니다:
  `?peerhost=내서버주소&peerport=443&peerpath=/&peersecure=1`
  (서버 띄우기: `npx peerjs --port 9000`)

## 채점 방식 (`js/color.js`)

1. 사진을 긴 변 160px로 줄입니다.
2. 사진 짧은 변의 12% 크기 정사각형을 촘촘히 옮겨 가며, 그 영역의 **평균색**과 목표색의 차이를 CIEDE2000(사람 눈 기준 색차 공식)으로 잽니다.
3. 가장 가까운 영역의 색차로 점수를 냅니다: `점수 = 100 × exp(-(색차 / k)^1.3)`
   - k = 30(후하게), 22(보통), 15(깐깐하게)
   - 보통 기준: 거의 같은 색 90점 이상, 비슷한 계열 60~80점, 다른 색 30점 아래
4. 아주 작은 점 하나로는 점수가 나오지 않아요. 물건이 화면에 어느 정도 크게 담겨야 합니다.

채점은 진행자 화면에서 하므로 참가자가 점수를 조작할 수 없습니다.
조명(형광등/햇빛)에 따라 같은 물건도 색이 달라 보이니, 같은 장소에서 하면 더 공정해요.
"다른 사람 휴대폰 화면의 목표색을 찍기 금지" 같은 규칙은 미리 정해 두세요.

## 파일 구조

```
index.html        모든 화면
css/style.css     디자인 (무채색 화면 + 목표색만 색으로)
js/color.js       색 변환, 색차(CIEDE2000), 사진 채점, 랜덤 목표색
js/net.js         실시간 연결 (진행자=방, 참가자=손님), 재접속, 생존 확인
js/ui.js          공통 화면 도우미, 효과음, 꽃가루
js/reveal.js      순위 발표 연출 (라운드 쇼, 누적 순위 자리바꿈, 최종 시상식, 휴대폰 슬롯 공개)
js/host.js        진행자: 방, 설정, 라운드, 사진 받기, 채점, 결과, 최종 순위
js/player.js      참가자: 입장, 팀 고르기, 카메라, 사진 보내기, 결과 보기
js/main.js        첫 화면, 주소(?room= / ?host=)에 따라 시작 화면 정하기
lib/peerjs.min.js PeerJS 1.5.5 (MIT 라이선스)
lib/qrcode.js     qrcode-generator 2.0.4 (MIT 라이선스)
```
